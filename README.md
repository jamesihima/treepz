# Treepz website

Static site — no build step.

- `index.html` — homepage
- `book-a-demo.html?product=parks|campus|school|staff|rideshare|interstate` — demo booking

## Deploy on GitHub Pages
1. Push this folder's contents to a repo's root.
2. Settings → Pages → Deploy from branch → `main` / root.

Notes: product videos stream from Higgsfield's CDN and partner logos load from treepz.com. The booking form shows a confirmation and offers a pre-filled email to marketing@treepz.com; connect a form backend to receive submissions.
